# Osobní stránka – Daniel Ajib

## Media rules

| Media rule | Co se mění a proč |
| :--- | :--- |
| `@media (min-width: ...)` | Přeskupí navigaci do řádku, vycentruje stránku a na širokém displeji srovná projekty do tří sloupců bez vodorovného posuvníku. |
| `@media (prefers-color-scheme: dark)` | Přepne stránku i posuvníky do tmavých barev pro pohodlnější čtení za šera. |
| `@media (prefers-contrast: more)` | Nastaví nejvyšší kontrast (WCAG AAA) a zesílí rámečky i podtržení odkazů pro lepší čitelnost. |
| `@media (prefers-reduced-motion: reduce)` | Vypne plynulé rolování a animace karet i odkazů pro uživatele citlivé na pohyb. |
| `@media (prefers-reduced-transparency: reduce)` | Nahradí průhledné pozadí karet a rozostření plnou barvou, aby byl text lépe čitelný. |
| `@media (forced-colors: active)` | Nastaví okraje karet, tabulek a fokusu pomocí systémových barev pro režim vysokého kontrastu ve Windows. |
